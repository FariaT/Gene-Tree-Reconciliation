Gene tree / species tree reconciliation

Enter a rooted species tree and a rooted gene tree in Newick format. The tool maps each gene-tree node to the species tree (LCA mapping) and counts duplications, losses, and extra lineages.

Up to 8 species. Example: ((A,B),(C,D))

Label each gene-tree leaf with its species letter. Repeat a letter when that species has multiple gene copies.

Examples:
0Duplications
0Losses
0Extra lineages (deep coalescence)

Duplication and loss counts assume the gene tree evolved by gene duplication and loss. Extra lineages are the alternative explanation, incomplete lineage sorting (the MDC cost).
