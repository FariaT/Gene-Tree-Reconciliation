Gene tree / species tree reconciliation

Enter a rooted species tree and a rooted gene tree in Newick format. The tool maps each gene-tree node to the species tree (LCA mapping) and counts duplications, losses, and extra lineages.

Up to 8 species. Example: ((A,B),(C,D))

How the counts work

Mapping. A gene leaf maps to its species. An internal node maps to the lowest species-tree node that is an ancestor of both children’s images.

Duplication. A node is a duplication if it maps to the same species node as at least one of its children. Otherwise it is a speciation.

Losses. For each gene-tree edge from parent v to child w, count the species-tree edges between M(w) and M(v). Subtract 1 if v is a speciation, since that gap is a normal split. Add the edges above the gene root up to the species root.

Extra lineages. For each species-tree branch, count the gene lineages that cross it, then sum (count − 1) over the branches that have at least one lineage.
